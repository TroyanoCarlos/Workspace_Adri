# Caso de Uso

El caso de uso el que nos permite dar contexto al objeto que vamos a diseñar. Es un lenguaje tecnico que permite explicar a la gente lo que se tiene en mente.

Diagrama de caso de uso:

- Elipse representa el proceso (conjunto de actividades, se denota en oraciones que empiece con verbo).
- Lineas representan relaciones.
  - Include.
  - Extense.
