# Programacion orientada a objetos

Propiedades son las variables en programacion estructurada.

Metodos son los procesos y funciones en programacion estructurada.

Para que las variables y procesos se vuelvan propiedades y los metodos necesitan un ambiente.

## Java

Dentro de Java esta el metodo main. El metodo main solo debe tener pocas lineas de codigo que lancen el programa.
